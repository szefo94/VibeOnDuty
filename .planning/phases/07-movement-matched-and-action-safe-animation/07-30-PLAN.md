## Retry rule for the stable gates (fixed here, before any run; answers review note S-01)

- Each gate is run in full at most twice at one source identity.
- A second full run of the offline or multiplayer gate is allowed without asking anyone only if all of these hold for the first run: at most two cases failed; each failure is a timeout in setup or navigation (a hook or page load) with no failed assertion; and the first run's log and report were copied byte for byte to new names (exclusive create) and committed before the second run starts.
- The gate passes only if the second run passes in full. It is then cited everywhere as "passed on run 2 of 2", with the failing titles of run 1.
- Any failed assertion, more than two failed cases, a failure of the same case in both runs, or a failed second run ends the gate as failed. There is no third run and no single-case rerun counted as the gate.
- Lint, the two typechecks, the build and the unit tests are run once; a failure there is a defect and ends the plan.
